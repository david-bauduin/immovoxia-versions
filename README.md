# ImmoVoxIA — versions publiées

Ce dépôt ne contient que les installateurs d'ImmoVoxIA et leur
`version.json`, publiés automatiquement à chaque nouvelle version. Le code
source n'est pas ici, et aucune donnée de client non plus.

Pour installer ImmoVoxIA : ouvrez la
[dernière version](https://github.com/david-bauduin/immovoxia-versions/releases/latest),
téléchargez `ImmoVoxIA-Setup-….exe` et double-cliquez dessus. Les mises à
jour suivantes se proposent ensuite d'elles-mêmes dans l'outil.
